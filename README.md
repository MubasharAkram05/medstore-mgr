# MedStoreMgr

Medical Store Manager. An offline Android app for a Pakistani medical store to track medicine prices (box / pata / tablet in Rs.) and record sales. All data is saved on the phone in `localStorage`. Nothing is sent to a server.

## Features

- Medicine list with search, Category / Form Type / Stock filters (remembered), sorting and bulk delete
- Stock in boxes / patas / loose tabs (bottles / units for syrups), auto-subtracted on every sale
- Low stock and out-of-stock alerts, restock (purchase) entries with history, stock value on Stats
- 800+ common Pakistani medicines preloaded
- Add / edit medicines with photo, form type, category, shelf place (R/L/B)
- Box pricing: box price, total tablets and patas auto-calculate pata and tablet rates
- PKR prescription calculator (patas + loose tablets)
- Quick sell and sales history (today / all time)
- Stats: revenue, items sold, stock value, low / out-of-stock counts, dosage form breakdown
- Profile (name, store, location, avatar)
- Backup and restore as JSON, remove duplicates, clear all data
- Works fully offline: Tailwind CSS, Lucide icons and the Inter font are bundled

## Project structure

## Build (Kali Linux / any Linux)

Requirements: Node.js 22+, Android Studio (SDK 36), JDK 21.

```bash
git clone https://github.com/MubasharAkram05/medstore-mgr.git
cd medstore-mgr
npm install
npm run sync                 # builds tailwind.css and copies www/ into android/
cd android && ./gradlew assembleDebug
```

Debug APK: `android/app/build/outputs/apk/debug/app-debug.apk`

Install on a phone (USB debugging on):

```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

Or copy the APK to the phone and open it. Allow "Install unknown apps" for your file manager when Android asks.

## Signed release APK

1. Create a keystore once. Keep it **outside** the repo:

   ```bash
   mkdir -p ~/keys
   keytool -genkeypair -v -keystore ~/keys/medstoremgr-release.jks \
     -alias medstoremgr -keyalg RSA -keysize 2048 -validity 10000
   ```

2. Copy `android/key.properties.example` to `android/key.properties` and fill in the path and passwords.
3. Build:

   ```bash
   npm run sync
   cd android && ./gradlew assembleRelease
   ```

Release APK: `android/app/build/outputs/apk/release/app-release.apk`

Keep the `.jks` file and its passwords safe and backed up. If you lose them you cannot update the installed app (you must uninstall it, which deletes its data). Never commit them. `.gitignore` already blocks `*.jks`, `*.keystore` and `key.properties`.

## Icon and splash screen

Edit `assets/icon.svg` (or replace the PNGs in `assets/`), then:

```bash
npm run assets               # npx @capacitor/assets generate --android
```

## Other commands

| `npm run build:css` | Rebuild `www/css/tailwind.css` after adding Tailwind classes |
| `npm run vendor` | Re-copy Lucide and the Inter font from `node_modules` |
| `npx cap open android` | Open the project in Android Studio |

## Moving old data into the app

The APK has its own storage, separate from your browser. Old data does not move by itself:
open the old HTML file in the browser, go to Profile, then Backup / Restore, then Export. Then use Import inside the app.
